================================================================================
                              DATABASE SCHEMA
================================================================================

TABLE: loan_applications
COLUMNS:
  - id (INT, PRIMARY KEY, AUTO_INCREMENT)
  - applicant_id (VARCHAR(100), UNIQUE, NOT NULL)
  - age (INT)
  - income (FLOAT)
  - employment_type (VARCHAR(50))
  - credit_score (INT)
  - loan_amount (FLOAT)
  - tenure_months (INT)
  - existing_liabilities (FLOAT)
  - location (VARCHAR(100))
  - application_timestamp (DATETIME)
  - status (VARCHAR(20)) - pending, approved, rejected, review

RELATIONSHIPS:
  - One-to-One with application_profiles (FK: application_id)
  - One-to-One with financial_risks (FK: application_id)
  - One-to-One with loan_decisions (FK: application_id)
  - One-to-One with compliance_records (FK: application_id)


TABLE: application_profiles
COLUMNS:
  - id (INT, PRIMARY KEY)
  - application_id (INT, FOREIGN KEY)
  - income_stability_score (FLOAT)
  - employment_risk (FLOAT)
  - credit_history_summary (VARCHAR(255))
  - completeness_flags (TEXT - JSON)
  - age_risk_factor (FLOAT)
  - analysis_timestamp (DATETIME)


TABLE: financial_risks
COLUMNS:
  - id (INT, PRIMARY KEY)
  - application_id (INT, FOREIGN KEY)
  - debt_to_income_ratio (FLOAT)
  - credit_score_risk_level (VARCHAR(50))
  - loan_amount_risk (VARCHAR(50))
  - anomaly_detected (BOOLEAN)
  - anomaly_reasons (TEXT - JSON)
  - risk_score (FLOAT)
  - reasoning (TEXT)
  - analysis_timestamp (DATETIME)


TABLE: loan_decisions
COLUMNS:
  - id (INT, PRIMARY KEY)
  - application_id (INT, FOREIGN KEY)
  - classification (VARCHAR(20)) - approved, rejected, review
  - risk_score (FLOAT)
  - confidence_level (FLOAT)
  - key_decision_factors (TEXT - JSON)
  - explanation (TEXT)
  - decision_timestamp (DATETIME)


TABLE: compliance_records
COLUMNS:
  - id (INT, PRIMARY KEY)
  - application_id (INT, FOREIGN KEY)
  - case_id (VARCHAR(100), UNIQUE)
  - action_taken (VARCHAR(255))
  - notification_sent (BOOLEAN)
  - audit_trail (TEXT - JSON)
  - created_timestamp (DATETIME)
  - processing_time_seconds (FLOAT)


================================================================================
                        API ENDPOINTS WITH DATABASE
================================================================================

1. POST /api/loan-application
   Input: LoanApplication JSON
   Output: LoanDecisionResponse with all analysis
   Database: Saves 5 records across all tables

2. GET /api/applications/{applicant_id}
   Output: Complete application with all linked data
   Database: Joins all 5 tables

3. GET /api/applications
   Query Params: skip, limit, status
   Output: List of applications
   Database: Paginated query

4. GET /api/applications/{applicant_id}/decision
   Output: Decision details only
   Database: Queries loan_decisions table

5. GET /api/statistics
   Output: Approval rates, totals by status
   Database: Aggregation queries

6. GET /database/status
   Output: MySQL connection status
   Database: Connection test query

7. GET /api/health
   Output: System health with DB status
   Database: Connection verification

================================================================================
                          HOW TO RUN THE SYSTEM
================================================================================

STEP 1: MySQL Setup
  1. Install MySQL Server
  2. Install MySQL Workbench
  3. Create database and user using provided SQL commands
  4. Update .env with credentials

STEP 2: Install Python Dependencies
  pip install sqlalchemy==2.0.23
  pip install pymysql==1.1.0
  pip install mysql-connector-python==8.2.0

STEP 3: Terminal 1 - Backend with MySQL
  python -m backend.main_with_db
  
  Expected: ✅ Database tables created successfully
           ✅ API running on http://127.0.0.1:8000

STEP 4: Terminal 2 - Frontend
  streamlit run frontend/streamlit_app.py
  
  Expected: Local URL: http://localhost:8501

STEP 5: Access and Test
  UI: http://localhost:8501
  API Docs: http://localhost:8000/docs
  DB Status: http://localhost:8000/database/status

================================================================================
                          TROUBLESHOOTING
================================================================================

"Connection refused"
→ Start MySQL service (see platform-specific commands in MYSQL_SETUP_COMPLETE.md)

"Access denied for user"
→ Verify password in .env matches MySQL
→ Run: FLUSH PRIVILEGES in MySQL Workbench

"No module named 'pymysql'"
→ pip install pymysql==1.1.0

"Unknown database"
→ Create database: CREATE DATABASE loan_approval_system;

"Tables not created"
→ Check database connection in .env
→ Or manually: python -c "from backend.database import create_all_tables; create_all_tables()"
